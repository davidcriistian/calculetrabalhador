# PROJECT_CONTEXT.md

## OBJETIVO DO PROJETO

O Portal Trabalhista é um portal especializado em calculadoras trabalhistas, direitos do trabalhador, benefícios e conteúdos educativos.

Objetivos principais:

* Gerar tráfego orgânico através de SEO.
* Monetizar através do Google AdSense.
* Criar ferramentas úteis para trabalhadores brasileiros.
* Produzir conteúdo educativo de alta qualidade.
* Construir autoridade no nicho trabalhista.

---

## REGRAS OBRIGATÓRIAS

Antes de qualquer alteração, seguir obrigatoriamente o fluxo:

ANÁLISE → PLANO → APROVAÇÃO → IMPLEMENTAÇÃO → TESTE → COMMIT

Nunca executar alterações sem apresentar previamente o plano.

Sempre explicar:

* O que será alterado.
* Quais arquivos serão alterados.
* Qual o impacto da alteração.
* Como será feito o teste.

Aguardar aprovação antes de implementar.

---

## RESTRIÇÕES

NUNCA alterar sem autorização:

* Home page.
* Header global.
* Footer global.
* URLs existentes.
* Estrutura de navegação.
* Sitemap.
* Robots.
* Arquivos já publicados.
* Arquivos de calculadoras existentes.

NUNCA:

* Excluir arquivos.
* Renomear arquivos.
* Quebrar links internos.
* Quebrar estrutura SEO.
* Alterar páginas existentes sem autorização explícita.

## ESTRATÉGIA DE ARTIGOS

Os artigos possuem dois objetivos:

1. Ranquear no Google.
2. Direcionar usuários para as calculadoras.

Toda produção de conteúdo deve criar conexão entre:

Artigo → Ferramenta

Exemplo:

* Artigo sobre férias → Calculadora de Férias.
* Artigo sobre rescisão → Calculadora de Rescisão.
* Artigo sobre seguro-desemprego → Calculadora de Seguro-Desemprego.
