# Cluster Blueprint

Esta pasta contem o modelo declarativo do Cluster Blueprint.

O documento canonico esta em:

```text
data/blueprints/docs/CLUSTER_BLUEPRINT.md
```

O Cluster Blueprint define o Cluster como unidade estrutural principal e organiza Calculator Blueprint, Article Blueprint, SEO, monetizacao, publicacao, testing e validation como componentes de um mesmo ecossistema.

O significado canonico de Dominio, Nucleo, Guia, Cluster, Calculadora, Artigo, Produto e CTA esta em `/docs/PLATFORM_ARCHITECTURE.md`. Este documento apenas aplica esse modelo ao Blueprint System.

Um Cluster Blueprint deve preservar `primaryDomain`, `primaryNucleus`, Calculadora principal quando aplicavel, Artigo pilar quando aplicavel e Artigos satelites em campos separados. Produtos, ofertas e CTAs permanecem elegiveis por configuracao, nao ownership estrutural do Cluster.

Esta camada nao cria clusters reais, nao gera paginas e nao altera producao.
