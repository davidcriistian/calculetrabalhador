# Cluster Blueprint

Esta pasta contem o modelo declarativo do Cluster Blueprint.

O documento canonico esta em:

```text
data/blueprints/docs/CLUSTER_BLUEPRINT.md
```

O Cluster Blueprint define o Cluster como unidade estrutural principal e organiza Calculator Blueprint, Article Blueprint, SEO, monetizacao, publicacao, testing e validation como componentes de um mesmo ecossistema.

Esta camada nao cria clusters reais, nao gera paginas e nao altera producao.
